# Задачи агентов

В Git хранятся только шаблоны и показательные примеры.

Реальная задача должна находиться:

1. предпочтительно в GitHub Issue / Pull Request;
2. либо локально в `tasks/active/<ID>.md`.

Каталоги `active` и `results` игнорируются Git, чтобы временные отчёты не
превращались в постоянную документацию.

## Рабочий цикл

```text
Issue или tasks/active/<ID>.md
        ↓
один агент / один worktree / одна ветка
        ↓
код + тесты + стенд
        ↓
результат по RESULT_TEMPLATE в PR/чате
        ↓
до 3 продуктовых вопросов владельцу
        ↓
правки по UX_FEEDBACK_TEMPLATE
        ↓
merge
```

## Команда агенту

```text
Прочитай AGENTS.md и задачу <путь или Issue>.
Работай только в назначенной ветке/worktree.
Не создавай дополнительные документы.
В конце ответь по tasks/RESULT_TEMPLATE.md.
```
